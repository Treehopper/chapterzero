# Third-party data and code

## Word data (shipped in `apps/pwa/public/packs`, downloaded by the app)

| Pack | Source | Licence |
|---|---|---|
| `words-en-de`, `forms-en` | English Wiktionary, © Wiktionary contributors, extracted with [Wiktextract](https://github.com/tatuylonen/wiktextract) and published by [kaikki.org](https://kaikki.org/dictionary/English/) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `words-de-freedict` | [FreeDict eng-deu 1.9-fd1](https://freedict.org/), derived from the TU Chemnitz "Ding" dictionary | GPL-2.0-or-later |
| ranks / levels (build time only) | [wordfreq](https://github.com/rspeer/wordfreq) data by Robyn Speer | CC BY-SA 4.0 |

The packs are adapted works: entries were filtered, merged per lemma, ranked by
frequency and cut to 140-character definitions. The Wiktionary-derived packs and the
FreeDict pack are kept as separate files and IndexedDB stores because their licences differ.

## Test fixtures

`fixtures/mini-pack` and `fixtures/mini-wordlist.json` are small excerpts of the packs above
(same licences). `fixtures/epub/omnibus-fixture.epub` is generated by
`tools/fixtures/make-epub.ts` (original text, public domain). Downloaded test books
(`fixtures/epub/downloaded`, not committed) come from Project Gutenberg and Standard Ebooks
and are in the public domain in the USA.

## Code dependencies

Bundled into the app: Svelte, Workbox, JSZip (dual MIT or GPL-3.0; used under MIT), pako
(MIT and Zlib), htmlparser2 and dom-serializer (MIT), domhandler, domutils, domelementtype
and entities (BSD-2-Clause), Dexie (Apache-2.0), @msgpack/msgpack (ISC). Build tools: Vite,
vite-plugin-pwa (MIT). See each package's licence in `node_modules`.

The app's own code is not open source; see `LICENSE`.
